# 貓咪金幣跑酷（kitty-gold-runner）

可愛小花貓無盡跑酷：自動往前跑，跳躍撿金幣、躲障礙。

## 開啟

```bash
cd "/workspace/agents/Game Designer/kitty-gold-runner"
/home/box/bin/godot --path .
```

操作：空白鍵／點擊／觸控 = 跳躍。

## 功能

- 標題 → 開始 → 撿金幣／躲障礙 → 遊戲結束 → 再玩一次
- 速度隨時間加快
- 繁中介面
- Web／PWA 匯出在 `build/web/`
